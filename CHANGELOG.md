# Changelog

## 5.1.0 (October 2026)

- Crisp and WhatsApp now work. Previously only Tawk.to did anything.
- Tawk.to accepts the full embed snippet as well as the widget ID.
- Settings are validated, and the module says what is missing instead of failing silently.
- Messenger removed (Meta retired its chat plugin in 2024).
- Joomla updater support through kindofuseful.com.
- Requires Joomla 5.0+ and PHP 8.1+.

## 5.0.0 (July 2025)

- First release: Tawk.to chat in the Joomla administrator.
